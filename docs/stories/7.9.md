# Story 7.9: Card Grid

**Epic:** 7 (Report Brick Library, Phase B)
**Status:** Review

## Story

As an author or agent,
I want a responsive grid of icon + title + description cards,
So that I can present a set of takeaways, features, or highlights (the "vision / benefits" summary) without a table or prose.

## Acceptance Criteria

**Given** a `card-grid` block with `columns` (1-N, capped) and `items` (each: optional `icon` from 7.6, `title`, short `description`)
**When** rendered
**Then** it renders as a responsive N-up grid of cards, each an optional icon + bold title + escaped one-line description, collapsing to one column at the reader mobile breakpoint

**Given** an item with no icon
**When** rendered
**Then** the card renders title + description only (the icon is optional), and an unknown icon key is an actionable validation error (FR2 parity)

**Given** the block
**When** audited
**Then** it is SSR, Zod-validated, renderer-pure, AAA on the default theme, within the reader budget, icon decorative with the title/description carrying meaning (NFR14)

## Dev Notes

- `columns` is an integer, capped at `MAX_CARD_COLUMNS = 4`: beyond four the cards crowd the reader column. `items` capped at `MAX_CARD_ITEMS = 24`, consistent with the field grid.
- Title/description are plain bounded strings, not rich inline runs (the field-grid stance: author prose, no `binding`). If a value ever needs inline formatting, that is an additive extension then, not a speculative one now.
- The renderer threads `block.columns` through a `--card-columns` custom property so the grid template is data-driven without inline-style arithmetic; the mobile collapse is pure CSS at the 768px breakpoint, mirroring the field grid. Zero hydration: the card grid ships no client JS.
- The icon is decorative by the 7.6 contract (`aria-hidden`, `focusable="false"`); the title and description carry the meaning, so the icon is never the sole signal (NFR14). A card with no icon renders title + description only.
- Card text uses `--report-text` / `--report-text-muted` (AAA report content on the default theme); the surface, rule and accent come from theme tokens, no raw hex in the component.
