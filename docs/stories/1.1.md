# Story 1.1: Project Scaffold & Quality Gates

Status: Approved

## Story

As the author-developer,
I want a scaffolded SvelteKit project with quality gates,
So that every future story builds on verified foundations.

## Acceptance Criteria

**Given** a clean clone
**When** `pnpm install && pnpm build && pnpm check && pnpm test` runs
**Then** all commands succeed on Node 22 with strict TypeScript and exact-pinned dependencies
**And** the build (scaffold per AR1 + `@sveltejs/adapter-node`) produces a runnable Node server

**Given** a push to GitHub
**When** CI runs
**Then** lint, svelte-check, vitest and build jobs pass (AR8)

## Tasks / Subtasks

- [ ] Scaffold SvelteKit at repo root via `npx sv create` (minimal template, TypeScript; add-ons: eslint, prettier, vitest, playwright) - scaffold in a temp dir and merge into the existing repo root without touching docs/, .claude/, _bmad*, .github/
- [ ] Swap adapter to `@sveltejs/adapter-node`; enable `strict` in tsconfig; pin exact dependency versions; add `.nvmrc` (22) and `engines` field
- [ ] Wire root `.gitignore` additions for SvelteKit outputs if missing (node_modules, .svelte-kit, build)
- [ ] Add a minimal landing route so build output is verifiable
- [ ] GitHub Actions CI: lint + svelte-check + vitest + build (`.github/workflows/ci.yml`)
- [ ] Verify all four commands pass locally; record versions in Dev Agent Record
